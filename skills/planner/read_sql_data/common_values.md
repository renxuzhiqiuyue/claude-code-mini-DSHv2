## yjhx_trans_detail（事实表）

### trans_dt（交易日期，月报主时间字段）

| 项 | 说明 |
|----|------|
| 类型 | `DATE` |
| 格式 | `YYYY-MM-DD`，如 `2025-01-01`、`2025-12-31` |
| 用途 | **月报时间过滤一律用此字段** |
| 比较 | 标准日期比较；**禁止**无横杠写法如 `'20250101'` |

```sql
-- 2025 年全年累计
t.trans_dt >= '2025-01-01' AND t.trans_dt <= '2025-12-31'

-- 2025 年 12 月单月
t.trans_dt >= '2025-12-01' AND t.trans_dt <= '2025-12-31'
```

| 取值 | 典型 prod_nm 示例 | 报告品类映射 |

| `家电` | 空调、洗衣机、冰箱、电视、电脑、热水器、家用灶具、吸油烟机 | 家电国补 / 家电地补 |

### rec_city_nm（收货城市）

**用途**：收货地、城市分布（query_06）。在事实表 `yjhx_trans_detail` 上直接过滤，**不代表分公司**。

| 常见误写 | 正确写法 |
|----------|----------|
| `'上海'` | `'上海市'` |
| `'北京'` | `'北京市'` |

```sql
-- 上海市的以旧换新交易笔数（城市口径，不需 JOIN usr_dim）
SELECT COUNT(*) AS trans_cnt
FROM yjhx_trans_detail t
WHERE t.rec_city_nm = '上海市'
  AND t.trans_dt >= '2025-01-01' AND t.trans_dt <= '2025-12-31'
  AND t.act_nm LIKE '%以旧换新%';
```

若问的是「上海分公司」，改用 `usr_dim.branch_org_nm`，见上文。

### act_nm（活动名称）

命名模式：`{分公司}以旧换新-{品类}`

示例：

- `四川分公司以旧换新-手机`
- `山东分公司以旧换新-手机`
- `上海分公司以旧换新-洗衣机`
- `上海分公司以旧换新-空调`

**过滤写法**：

```sql
-- 全部以旧换新活动
t.act_nm LIKE '%以旧换新%'

-- 指定分公司活动（与 scope 一致；地域过滤优先用 u.branch_org_nm）
t.act_nm LIKE '%四川分公司以旧换新%'

-- 家电品类（配合 prod_tp）
t.act_nm LIKE '%以旧换新%' AND t.prod_tp = '家电'
```

## usr_dim（用户维度）

### branch_org_nm（分公司，36 个）

**用途**：月报 scope、用户所属分公司统计。**须** `JOIN usr_dim u ON t.usr_id = u.usr_id` 后过滤。

```
上海分公司、云南分公司、内蒙分公司、北京分公司、厦门分公司、吉林分公司、
四川分公司、大连分公司、天津分公司、宁夏分公司、宁波分公司、安徽分公司、
山东分公司、山西分公司、广东分公司、广西分公司、新疆分公司、江苏分公司、
江西分公司、河北分公司、河南分公司、浙江分公司、海南分公司、深圳分公司、
湖北分公司、湖南分公司、甘肃分公司、福建分公司、西藏分公司、贵州分公司、
辽宁分公司、重庆分公司、陕西分公司、青岛分公司、青海分公司、黑龙江分公司
```

**分公司 scope 过滤**（精确匹配，**禁止** `LIKE`）：

```sql
-- 上海分公司的交易笔数
JOIN usr_dim u ON t.usr_id = u.usr_id
WHERE u.branch_org_nm = '上海分公司'
```

**与城市的区别**：

| 问法 | 字段 | 表 |
|------|------|-----|
| 上海**分公司**交易笔数 | `branch_org_nm = '上海分公司'` | `usr_dim`（JOIN） |
| 上海**市**以旧换新交易笔数 | `rec_city_nm = '上海市'` | `yjhx_trans_detail` |

「上海分公司」≠「上海市」，不可互换。

### usr_city_nm（用户常驻地）

与 `rec_city_nm` 不同，为用户维度字段；筛选分公司仍用 `branch_org_nm`，不用 `usr_city_nm` 代替。

### sex（性别，2 个）

`男`、`女`

### trans_level（交易水平，3 个）

`低`、`中`、`高`

### age（年龄）

整数，范围约 18~100。报告 age_group 分桶：`20岁以下`、`20-29岁`、`30-39岁`、`40-49岁`、`50-59岁`、`60岁及以上`。
